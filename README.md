### About me

I build in Unity across game dev, VR, and real-time 3D graphics, including custom shaders (ShaderLab).
A serious game for rehab therapy, a Unity + Python sensor-painting tool over UDP, and some Python/Jupyter work
visualizing phone sensor data round out the mix. Still learning and shipping small projects along the way.
